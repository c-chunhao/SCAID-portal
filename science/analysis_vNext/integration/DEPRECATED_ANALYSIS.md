# Compatibility and replacements for historical analysis scripts

The following historical scripts are retained for provenance and must not be used as entry points for new analyses:

- The benchmark section of `legacy/AID/T_NK/01.QC.Mult/01.QC.Mult.R` calculates LISI on the two-dimensional UMAP and uses each algorithm's own clusters as cell-type labels. This quantity describes only the two-dimensional display and that method's own clustering structure; it cannot establish preservation of biological signal or identify the best integration method.
- `legacy/AID/B_Plasma/02.scAnn/Mult_04/Mult_04.R` reads a base object named `scRNA.Mult2` but subsequently calls `subset(scRNA.Mult1, ...)`. A standalone run cannot find `scRNA.Mult1`; an object left in an interactive session could instead introduce the wrong source.
- Historical multi-algorithm reduction/cluster assignments only display the result of `identical(...)` rather than reject an incorrect order. New workflows must match by cell ID and check missing IDs, duplicates and order before every attachment.
- The CellTypist input in `T_NK/02.scAnn/Mult_01/Mult_01.R` subsets HVG counts before renormalization and cannot serve as the input specification for new annotations. Masking TCR/IG during integration can keep clonal signals from dominating the display, but annotation input must reread full RNA counts rather than use the masked integration feature set.
- `cross_disease_analysis/06_integration_quality.R` interprets raw iLISI as "higher is better," ignoring study confounding with condition/tissue/lineage. Its full-distance silhouette allocation is too large, and `geom_text_repel()` is used without explicitly loading `ggrepel`. New diagnostics hold condition, tissue and lineage fixed, use bounded subsampling, and calculate metrics in the high-dimensional latent space. Results state the space and coverage used.

`integration_safeguards.R` replaces unsafe positional attachment, merging of unnamed base objects and HVG-library normalization. It has been validated with reordered, missing and duplicate axes and with full-library normalization. `released_rna.py` reads the H5 schema and feature axes. `audit_metadata_and_latent.py` is the reproducible diagnostic that was executed. `reannotate_t1d_full_rna_pilot.py` is the full-RNA reannotation pilot that was executed; it outputs candidate labels and review status without automatically overwriting original labels with new model results.

Future integration parameters must freeze the seed, software/reference-model versions, sample and study keys, HVG set, dimensions, cluster resolution and cell-order provenance. Cell-cycle effects are not removed by default. If cell-cycle regression is compared, report its effect on retention of the Cycling population. When study/tissue/disease lack independent replication, complete mixing cannot be the optimization objective, and unidentifiable confounding cannot be reinterpreted as a disease mechanism.
